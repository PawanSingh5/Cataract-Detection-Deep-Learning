# Cataract Detection using Deep Learning

This project detects cataract disease from eye images using a deep learning model based on MobileNetV2.

## 📌 Features
- Binary classification (Cataract / Normal)
- Transfer Learning with MobileNetV2
- Image augmentation
- Medical image analysis

## 🧠 Model
- Architecture: MobileNetV2
- Loss: Binary Crossentropy
- Optimizer: Adam
- Input size: 224x224

## 📂 Dataset Structure
processed_images/
├── train/
│   ├── cataract
│   └── normal
└── test/
   ├── cataract
   └── normal
